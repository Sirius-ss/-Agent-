# ADR-0001 · 单台设备维修工单与显式确认

状态：待技术评审。依据：[PRD 第 6 节](../../PRD.md)。

现有 AfterSale 关联整单，并按订单查找进行中的申请。同单同款购买两台时，消费者可以分别为两台设备报修。另外，现有客服 Worker 会丢弃被插话取代的 AI 结果；在模型运行期间写工单会产生用户尚未确认的持久化结果。

决定在业务服务增加单台设备、不可变预览与 RepairTicket，由用户页面显式确认。以原预览 ID 处理重放，以数据库唯一约束处理同设备重复建单。Agent 只返回页面动作。

复用原售后表可以少建实体，但需要同时更改退换货去重范围和状态语义。模型直接调用写工具可以减少一次页面交互，却无法证明用户确认的是哪一份内容。选定方案增加一次预览请求及少量新表，换取独立授权、可审计的确认和单库事务边界。
